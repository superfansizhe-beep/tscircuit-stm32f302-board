# 器件清单 BOM — STM32F302R8T6 考核板

> **封装策略**：全部走 `jlcpcb:Cxxxx`（嘉立创/EasyEDA 真实封装），**不自绘库、不手写焊盘**。
> **结论先说**：23 种器件的封装**库里全部都有**，焊盘数与引脚数逐一核对无误，**没有一个需要自己画库**。

---

## 2. 电感与晶振

| 位号 | 型号 | 封装 | C 编号 | 关键参数 | 数量 |
|------|------|------|--------|----------|:---:|
| **L1** | CKCSA4020-4.7µH/M | SMD 4×4mm | `C354583` | 4.7µH，**Irms 2.85A / Isat 4A**，110mΩ | 1 |
| **Y1** | TAXM8M4RDBCCT2T | SMD3225-4P | `C400090` | 8MHz 无源，负载 10pF，±10ppm | 1 |

> **L1 选型依据**：RY8411 为 1.2A 输出，12V→5V 时电感纹波电流约 0.78A，
> **峰值电流约 1.59A**，故要求 Isat > 1.6A 并留余量。
> 已淘汰的候选：`C19398` SWPA3015（Isat 仅 1.4A，不够）、
> `C354574` CKCS4018（Isat 1.7A，余量仅 7%，太薄）。
>
> ⚠️ **Y1 必须选无源晶振**。检索结果里混有大量有源振荡器（SiT8008 / SG-8018CE 等），
> 不要误选 —— MCU 的 HSE 要无源。

## 6. 无源件（封装统一 0603）

| 类别 | 值 | C 编号 | 说明 |
|------|-----|--------|------|
| 电阻 | 10kΩ | `C25804` | `0603WAF1002T5E`，嘉立创基础库 |
| 电阻 | 1kΩ / 100kΩ / 4.7kΩ / 22kΩ 等 | 同系列 `0603WAF****T5E` | 均为基础库，库存千万级 |
| 电容 | 100nF | `C14663` | `CC0603KRX7R9BB104`，基础库 |
| 电容 | 22µF / 4.7µF / 1µF / 10nF | 0612 或 0805 系列 | 待电路定值后补编号 |

> **为什么这里只列基础值**：无源件的**具体阻容值和数量要等电路设计完成才能定**
> （分压电阻、去耦数量、限流电阻、上拉电阻、晶振负载电容…）。
> 封装已经锁定 **0603**（符合要求 10），基础库编号拿到后逐个填即可。
>
> ⚠️ 大容量电容（22µF / 4.7µF）在 0603 里耐压与容值受限，
> 可能需要放到 **0805**（题目允许 0603 或 0805），届时在 BOM 里标注。

## 7. 封装库验证（本 BOM 的核心结论）

### 验证方法

不是照文档抄，而是**把每种器件实际实例化一遍，强制解析封装，然后逐个数焊盘**：

```bash
cd ~/Desktop/tscircuit/my-tscircuit
export PATH="$HOME/Desktop/tscircuit/.tooling/bun/bin:$PATH"

# 1) 出图：任何封装解析失败都会在这里暴露
./tsci-run export circuits/stm32f302/_libcheck.tsx -f pcb-svg -o ../../out/stm32f302/_libcheck.svg

# 2) 出 circuit-json，逐器件数焊盘
./tsci-run export circuits/stm32f302/_libcheck.tsx -f circuit-json -o ../../out/stm32f302/_libcheck.json
```

### 结论

| 问题 | 答案 |
|------|------|
| 库里有对应封装吗？ | ✅ **23 种全部都有** |
| 需要自己画库吗？ | ❌ **一个都不需要** |
| 焊盘数对得上引脚数吗？ | ✅ **23/23 全部匹配**（含 LQFP-64 的 64 脚） |

**封装来源**：`jlcpcb:Cxxxx` 直接拉取 EasyEDA 真实封装 —— 焊盘几何、丝印、位号
与嘉立创 SMT 下单时用的**完全一致**，不引入手抄误差。

> 附带收获：这批封装**通孔焊盘不会被生成锡膏开口**（SMT 焊盘 147、通孔 52 分开计数），
> 直接可用于制造层输出。
