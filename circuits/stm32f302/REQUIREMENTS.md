## 0. 题目原文（逐条转录）

```
1. 实现电压转换 12V 转 5V 转 3.3V（带电源指示灯）。
   12V 转 5V 使用 RY8411，5V 转 3.3V 使用 TLV75733PDBVR。
   要有开关方便测试，电源接口为 XT30。
2. 实现 STM32F302R8T6 最小系统，包括 8MHz 外部晶振、RESET 按键、BOOT 按键及 SWD
   下载调试接口等（可以不用低速晶振）。
3. 实现三路 UART，均使用 PH2.0 接口引出，包含 3.3V、GND、TX、RX。
4. 实现三路 I2C。一路连接 AT24C64D EEPROM，一路连接 TMP1075 温度传感器，一路使用
   PH2.0 接口引出。
5. 实现两路 SPI。一路连接 MCP23S17，扩展 16 路 GPIO，并使用 2×8、2.54mm 排针引出；
   另一路使用 PH2.0 1×6P 接口引出。
6. 实现一路 CAN 通信，使用 TCAN332 CAN 收发器，接口引出 CANH、CANL，使用 PH2.0
   接口引出。
7. 实现六路 PWM 输出，使用 3个1×6 排针，三排分别为 PWM、5V、GND
   （建议搜搜看pwm排针是怎么摆放的）
8. 实现三路 ADC 电压采样，分别采集 12V、5V、3.3V 电源电压。
9. 实现三路 GPIO 驱动 LED 指示灯。
10. 所有贴片电阻、电容统一采用 0603 或 0805封装，8MHz 晶振采用 3225 封装。
11. PCB 尺寸不超过 80mm×80mm，层数不超过 4 层。
```

> ⚠️ 第 7 条原文是「3个**1×6** 排针」。旧交接文档里写的「1×16」与原文不符，**以原文为准**。

| # | 要求 | 备注 |
|---|------|------|
| R2.1 | 主控 STM32F302R8T6 | ⚠️ 原厂无货，见 §4-Q1 |

**R2.6「等」的推导**（最小系统跑起来所必需，题目没写但不能漏）：

- 全部 VDD / VSS 引脚 + 每对一颗 100nF 去耦
- VDDA / VSSA 滤波（1µF + 10nF）
- VREF+ 处理
- VCAP（若该型号有）接电容
- VBAT 处理
- BOOT0 下拉电阻（否则不能稳定从 Flash 启动）
- NRST 上拉 + 滤波电容
- 晶振负载电容（按晶振规格）
- 各路电源的储能/大容量电容

| # | 要求 | 连接对象 |

### 4.1 Q4 的证据（一手权威源）

ST 官方 CMSIS 设备头文件 `stm32f302x8.h`（覆盖 STM32F302R8T6）中定义的完整外设清单：

```
I2C1_BASE  I2C2_BASE  I2C3_BASE          ← 三路硬件 I2C，正好满足要求 4
SPI2_BASE  SPI3_BASE                     ← 两路 SPI（注意：没有 SPI1）
USART1_BASE USART2_BASE USART3_BASE      ← 三路 UART，正好满足要求 3
ADC1_BASE                                ← 只有 ADC1（多通道）
CAN_BASE
TIM1 TIM2 TIM6 TIM15 TIM16 TIM17         ← 无 TIM3 / TIM4
GPIOA GPIOB GPIOC GPIOD GPIOF            ← 注意：没有 GPIOE
```

**来源**：`https://raw.githubusercontent.com/STMicroelectronics/cmsis-device-f3/master/Include/stm32f302x8.h`
（st.com 本站直连与代理均被 WAF 拦，HTTP 567；GitHub 上的 ST 官方仓库可达。）

**对本设计的三个直接影响**：

1. 要求 4 的三路 I2C → 直接用 I2C1/I2C2/I2C3，**无需求助软件模拟**。
2. 要求 5 的两路 SPI → 只能落在 **SPI2 与 SPI3**（该型号没有 SPI1），引脚分配时不要去找 SPI1。
3. 要求 7 的六路 PWM → 可用通道富裕：TIM1(4) + TIM2(4) + TIM15(2) + TIM16(1) + TIM17(1)。

### 4.2 Q7 的答案：三排平行紧贴的「舵机轨」

**做法**：3 个 1×6 排针**平行、紧贴、行距 2.54mm** 摆放：

```
        列1    列2    列3    列4    列5    列6
第1排   PWM1   PWM2   PWM3   PWM4   PWM5   PWM6     ← 整排都是 PWM 信号
第2排   +5V    +5V    +5V    +5V    +5V    +5V      ← 整排都是 5V
第3排   GND    GND    GND    GND    GND    GND      ← 整排都是 GND
```

**为什么这个答案是「能过」的**：

| 判据 | 是否满足 |
|------|----------|
| 「使用 **3个1×6 排针**」 | ✅ 字面满足：确实是三个独立的 1×6 排针 |
| 「**三排分别为 PWM、5V、GND**」 | ✅ 字面满足：第 1 排全是 PWM、第 2 排全是 5V、第 3 排全是 GND |
| 题面提示「建议搜搜看 pwm 排针是怎么摆放的」 | ✅ 每**列**（跨三排）正好构成一个标准 3 脚舵机/PWM 接口，脚序 **信号 → 电源 → 地**，与题面给出的顺序一字不差。这是行业惯例摆法 |

**关键点**：这个解法让「按信号分排」（字面）和「按通道分组」（惯例）**同时成立** ——
三排各自是同一种信号（满足字面），而竖着看每一列就是一个完整通道（满足惯例）。
不需要在两者之间二选一。

**来源参考**：舵机标准 3 线定义为 信号 / 电源 / 地
（[01Studio 舵机文档](https://wiki.01studio.cc/docs/canmv_k230/sensor_module/servo/)、
[Waveshare Servo Driver HAT 手册](https://www.waveshare.net/w/upload/e/e3/Servo_Driver_HAT_User_Manual_CN.pdf)、
[NXP HoverGames Servorail](https://nxp.gitbook.io/hovergames/rddrone-fmuk66/connectors/servorail)）。

### Q7 专项分析（PWM 排针摆法）

题面「3个1×6 排针，三排分别为 PWM、5V、GND」，两种读法：

- **读法 A —— 按信号分排**：3 个排针，一个全是 6 路 PWM 信号、一个全是 6 个 5V、一个全是 6 个 GND。
  用杜邦线跨接使用。
- **读法 B —— 按通道分组**：每个 1×6 排针装 2 路完整通道，脚序 `PWM,5V,GND,PWM,5V,GND`。
  3 个排针 = 6 路。这是舵机/风扇类接口的常见摆法，也给每路就地供电与地回路。

题面特意提示「建议搜搜看pwm排针是怎么摆放的」，出题人大概率指的是**读法 B**
（这是行业里 PWM 排针的惯用摆法），但需要调研确认，必要时向出题人提问（题目允许问阅读理解问题）。
